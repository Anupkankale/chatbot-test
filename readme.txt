An intelligent, AI-powered assistant designed for Web Development Agencies to automate project qualification and lead capture.

== Description ==

DevXpert Digital Project Assistant is an intelligent strategist designed specifically for web development and digital agencies. It features a modern Navy & Blue interface, seamless Claude AI integration for RAG (Retrieval Augmented Generation), and a robust lead-capture pipeline.

Features:
* 🤖 AI-powered project guidance using Claude API.
* 📚 Retrieval Augmented Generation (RAG) based on your agency's site content.
* 📋 Lead Capture pipeline for project briefs, budgets, and platforms.
* 📬 Integrated newsletter subscription popup.
* 📧 SMTP delivery settings for reliable lead alerts.
* ⚡ Sleek, modern Admin UI matching the chatbot aesthetic.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/chatbot` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen on WordPress.
3. Use the DevXpert Chatbot menu to configure your agency branding and AI knowledge base.

== Frequently Asked Questions ==

= Do I need an API key for Claude? =
Yes, a Claude API key from Anthropic is required to enable intelligent AI responses based on your website content.
