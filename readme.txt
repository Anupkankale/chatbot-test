== Description ==

DevXpert Chatbot is an intelligent assistant designed for talent acquisition and consultation services. It features a modern dark-themed interface, seamless Claude AI integration for RAG (Retrieval Augmented Generation), and built-in lead generation capabilities.

Features:
* Professional AI-powered responses using Claude API.
* Retrieval Augmented Generation (RAG) based on your site content.
* Newsletter subscription popup.
* SMTP delivery settings for reliable notifications.
* Lead tracking and management.
* Sleek, customizable dark theme.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/devxpert-chatbot` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen on WordPress.
3. Use the DevXpert Chatbot menu to configure settings.
